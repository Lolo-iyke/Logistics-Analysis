# 📦 Logistics & Supply Chain Performance Analysis

An end-to-end data analytics project examining operational efficiency, delivery performance, and supply chain bottlenecks using excel and Power BI.

---

## 📊 Project Overview
This project provides data-driven insights into logistics operations, helping stakeholders identify delivery delays, track regional fulfillment metrics, and optimize overall supply chain efficiency. 

* **Dashboard File:** `cap.pbix`
* **Primary Tool:** Microsoft Power BI and Excel
* **Domain:** Supply Chain & Logistics Analytics

---

## 🚀 Key Performance Indicators (KPIs) & Insights
The interactive dashboard tracks several core logistics metrics:
* **On-Time Delivery (OTD) Rate:** Percentage of shipments delivered on or before the promised date.
* **Shipping & Transit Times:** Average duration from order placement to final delivery across different transport modes.
* **Regional Performance:** Identification of high-performing regions vs. bottleneck locations with frequent delays.
* **Order Status Breakdown:** Real-time visibility into fulfilled, delayed, and canceled shipments.
